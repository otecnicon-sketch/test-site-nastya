# Вязаные сказки Насти — сайт-визитка

Одностраничный сайт сообщества «Вязаные сказки Насти» (вязаные игрушки и подарки ручной работы, Пермь, Култаево).

- **index.html** — разметка страницы
- **styles.css** — стили (тёплая кремово-коричневая палитра, Playfair Display + Rubik + Caveat)
- **app.js** — интерактивность: галерея с cross-fade, аккордеон, плавное появление блоков, подсветка активного пункта меню
- **img/** — фотографии игрушек и портрет мастера с баннера сообщества ВК

## Защита

- Content Security Policy через мета-тег (без inline-скриптов и стилей)
- Все внешние ссылки с `rel="noopener"`, реферер-политика `strict-origin-when-cross-origin`
- Без форм, cookies и сторонних трекеров — поверхность атаки минимальна

## Просмотр

Откройте `index.html` в браузере или запустите статический сервер:
`python -m http.server 7100`
